# Release Notes

## Latest Changes

## 0.1.0

Initial release of the Django VS Code extension.

### Features

* URL pattern discovery — automatically finds `urlpatterns` lists in your Django project.
* Path Operation Explorer — hierarchical tree view of all Django URL patterns.
* Search routes — quickly search for routes by path, method, or name via `Ctrl+Shift+E`.
* CodeLens navigation — jump from test client calls to matching route definitions.
* Multi-root workspace support.
* Support for `pyproject.toml` entrypoint configuration via `[tool.django]`.
* Support for vscode.dev (browser-based editing).
